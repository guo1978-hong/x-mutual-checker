# 互关检测助手 · 名单保护版

基于 [lonly2010/x-mutual-checker](https://github.com/lonly2010/x-mutual-checker) 的增强 fork，增加近期关注保护、永久白名单、粉丝数双向排序与竖屏布局。上游代码及图标归原作者；本项目不代表 X，也不代表上游商店版。

本仓库保留与上游的 fork 关系。Chrome 商店版本尚未上架，没有本增强版的商店安装链接。

## 功能

- 查看未回关、曾互关后取消关注的名单；首次扫描不凭空推断历史取关。
- 排除今天或近7天的新关注。未知日期继续显示，清楚标注「关注日期未知」，也可选保护未知日期账号。
- 永久白名单：单个或批量加入、查看、搜索、移出恢复、导出；原忽略项首次升级迁入。
- 粉丝数升降序；未知数值排最后，0参与正常排序。
- 上下移动面板、调整高度、铺满与重置；在竖屏显示更多账号。
- 按当前筛选和排序导出CSV，附关注时间依据。

## 日期依据

旧历史名单没有可靠的关注日期。本项目不会使用账号注册日期或首次扫描日期冒充关注日期。在本机扩展开启时观察到网页关注操作，可保存本机观察时间；两次完整扫描之间新增的账号只能得到一个时间区间。手机或其他设备上的关注操作不会自动变成本机精确日期。

## 开发版安装与升级

下载源码后，在Chrome扩展管理页开启开发者模式，选择「加载已解压的扩展程序」，加载 `x-mutual-checker/`。在X网页点扩展图标开启。

已有同一开发版的用户，保留原目录与扩展ID，等当前任务结束后重新加载扩展并刷新X。不要卸载或删除本地数据。原商店版和本fork的扩展ID、存储独立，不能承诺自动继承商店版的历史。

## 本地数据与测试

扫描结果、白名单、日期依据、设置只存放在浏览器本地，按X账号区分。没有开发者后端或遥测。用户点击并确认的取关操作会发送给X；白名单和近期保护会在执行前再次检查。请阅读隐私政策。

开发测试：`node --test tests/*.test.cjs`。本地打包：`python scripts/package_extension.py`。界面预览：`python -m http.server 8874 --bind 127.0.0.1`，访问 `/preview/`；预览使用虚构账号，不连接X接口。

1.9.4共26项单元测试通过，包含15项日期／名单／布局测试及11项后台回退授权测试。虚构数据浏览器界面验证与包结构检查已有记录。真实Chrome已核验构建20261031.2、旧快照加载、粉丝数升降序、近7天筛选下未知日期继续显示和白名单页面；测试后恢复原设置，未发起真实扫描、关注或取关。不承诺X接口始终可用或平台不会限流。后台回退需要一次性授权，普通URL参数不能触发取关。
